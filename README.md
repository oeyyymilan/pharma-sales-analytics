# Pharma Sales & Market Analytics Dashboard

**SQL · MySQL · Power BI**

End-to-end analytics project: a MySQL star-schema database, SQL pipeline that cleans and aggregates pharmaceutical sales data across **regions, drug categories and sales reps**, and an interactive **Power BI dashboard** with **15 custom DAX measures** and **drill-through filters** to track sales trends and **YoY growth** by region.

> Data is synthetic (generated by `data/generate_data.py`, seeded for reproducibility) and deliberately dirty so the cleaning step does real work.

## Pipeline
| Step | File | What it does |
|---|---|---|
| 1 | `sql/01_schema.sql` | Creates `pharma_sales` DB: 3 dimensions, staging table, fact table (generated revenue columns, indexes, constraints) |
| 2 | `sql/02_load_data.sql` | Loads CSVs into dimensions and the all-text staging table |
| 3 | `sql/03_cleaning.sql` | Profiles data issues, then cleans → `fact_sales`, with reconciliation + rejected-rows audit view |
| 4 | `sql/04_analysis_queries.sql` | 10 business queries (region/category revenue, rep ranking, MoM, YoY, top-N, running totals, seasonality, discount impact, coaching list) |
| 5 | `sql/05_powerbi_views.sql` | `dim_date` calendar + report-ready views for Power BI |

### Data-quality issues found and fixed (13,535 raw rows → 12,994 clean)
| Issue | Rows | Fix |
|---|---|---|
| Duplicate transactions | 265 | `ROW_NUMBER()` per `txn_id`, keep first |
| Missing units | 150 | Rejected (logged in `v_sales_rejected`) |
| Negative units | 127 | Rejected (logged in `v_sales_rejected`) |
| Missing unit price | 378 | Imputed from `dim_drug` master price |
| Missing discount | 272 | Defaulted to 0 |
| Mixed date formats (`dd/mm/yyyy`) | 1,990 | Parsed per format |
| Inconsistent region text (case/whitespace) | 506 | `LOWER(TRIM())` matching to dimension |

## Quick start
```bash
git clone https://github.com/<your-username>/pharma-sales-analytics.git
cd pharma-sales-analytics
./run_all.sh root            # or run sql/01..05 in MySQL Workbench / the mysql CLI, in order
```
Requires MySQL 8.0+ with `local_infile` enabled (`SET GLOBAL local_infile = 1;`).
Then open Power BI Desktop and follow [`powerbi/dashboard_build_guide.md`](powerbi/dashboard_build_guide.md); measures are in [`powerbi/DAX_measures.md`](powerbi/DAX_measures.md).

## Power BI dashboard
- **Page 1 – Executive Overview:** KPI cards, revenue vs last year, region and category breakdowns, slicers
- **Page 2 – Regional YoY:** matrix by region → category × year with YoY % conditional formatting
- **Page 3 – Sales Rep Performance:** ranking, discount vs order value scatter
- **Page 4 – Drug Detail:** drill-through target (also a Region Detail drill-through)

## Sample findings (from this dataset)
- **West** (24.0%) and **North** (23.7%) lead revenue; **Central** trails (13.5%).
- **Antibiotics** and **Respiratory** are the top categories; Salbutamol Inhaler is the single highest-revenue drug.
- **East** grew +25.3% in 2024 but fell −3.0% in 2025; **South** held steady at about +15% growth both years.
- Deeper discounts did **not** lift order size (avg units ≈ 129–131 at every discount level), so average order value falls as discount rises.
- Respiratory units spike in Nov–Dec; antibiotics in monsoon months (seasonality query).
